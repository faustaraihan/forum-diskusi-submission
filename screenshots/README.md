# Bukti CI/CD submission

Folder ini digunakan untuk screenshot asli dari repository `faustaraihan/forum-diskusi-submission`:

1. `1_ci_check_error.jpg`: CI gagal karena assertion test gagal.
2. `2_ci_check_pass.jpg`: CI lolos setelah test diperbaiki.
3. `3_branch_protection.jpg`: halaman PR menunjukkan proteksi `master` dan required check.

Bukti dibuat dari halaman GitHub setelah run terkait selesai. File ini bukan pengganti ketiga screenshot. URL run, PR, dan status verifikasinya dicatat pada `SUBMISSION_NOTES.md`.
